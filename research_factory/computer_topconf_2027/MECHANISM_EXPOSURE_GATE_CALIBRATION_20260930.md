## 1. Failure mode exposed by OI-AS

The OI-AS line passed several upstream-looking screens:

- static hard headroom: 42/210 executable AgentSquare ALFWorld combinations flagged by frozen responsibility rules;
- weak component-level direction: MemoryTP shipped score 0.36, lowest among non-None memory modules;
- manipulability: OI-AS-02A successfully removed current-task plan authority from TP while preserving the memory path.

But the load-bearing causal story required more than dual structural presence. It required **material planner-vs-memory plan conflict to actually occur**.

Observed after the mechanism itself was screened:

- OI-AS-02B checkpoint pilot: Original TP 2/5, OI-TP 2/5, 0 discordant checkpoints;
- OI-AS-03/OI-AS-04 complete eligible exposure screen: 0 material macro-plan conflicts / 6 frozen targets;
- OI-AS-05: no independent residual soft seam admitted;
- final line verdict: TERMINATE AgentSquare/ALFWorld O+I.

Therefore the selector error was:

`STATIC_HEADROOM / POSSIBLE ROLE OVERLAP -> intervention authorization`

without an explicit intermediate gate:

`does the load-bearing relation actually occur?`

## 2. Selector mutation

New live rule:

`STATIC_HEADROOM != MECHANISM_EXPOSURE`.

Before a family-specific PRECARD or METHOD intervention, if the causal claim requires a runtime relation such as conflict, disagreement, competition, stale-state survival, mismatch, collision, or another event that can be absent despite structural possibility, freeze and test a **MECHANISM_EXPOSURE_PREDICATE** first.

The exposure gate must freeze:

1. target population / denominator;
2. event predicate at the same abstraction level as the causal claim;
3. minimum sufficient source/baseline probe;
4. action on zero exposure.

Allowed outcomes:

- EXPOSURE_SOURCE_PROVEN;
- EXPOSURE_EMPIRICAL_PASS;
- NO_EXPOSURE;
- EXPOSURE_NONIDENTIFIABLE.

A complete preregistered NO_EXPOSURE screen terminates the mechanism seam. Do not hunt for a seventh favorable example, redefine the event, or substitute occupancy rate.

Hierarchical producer→consumer handoff is not same-level conflict exposure merely because both modules contribute information.

## 4. Scope / anti-overcorrection

This mutation does NOT say:

- static structure is useless;
- every mechanism needs an expensive prevalence study;
- NO_EXPOSURE kills the whole interface/field;
- an exposure gate replaces occupancy, identifiability, or kill-scope logic.

It says only:

> when endpoint harm depends on a relation that may fail to instantiate even though its ingredients are structurally present, intervention authorization requires evidence that the relation is actually exposed.

Source proof can satisfy the gate when pinned semantics force the harmful relation independent of runtime values.

## 5. Forward-validation boundary

OI-AS is a calibration case because its outcome is now known.

The next genuinely new live candidate must apply MECHANISM_EXPOSURE_GATE prospectively before its first family-specific intervention whenever the causal story requires an instantiable runtime relation.
