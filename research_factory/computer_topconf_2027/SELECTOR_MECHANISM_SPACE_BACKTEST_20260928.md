## 0. Claim

The dominant live-selection error is no longer Phase-0 reconstruction. It is a greedy topic-formation transition:

`frozen residual/interface -> one natural repair -> occupancy or cheap negative -> leave interface/field`.

The proposed mutation inserts a bounded mechanism-space object:

`interface -> 2-4 causal families -> complete-claim screens -> family discriminator -> preregistered handoff`.

## 1. Correctness invariant

The mutation is accepted only if it separates three cases that the old workflow tended to collapse:

1. local method failure while interface pressure survives -> retain interface, kill only family;
2. necessary-condition failure for a specific family -> keep family killed, no parameter rescue;
3. complete-claim direct occupancy -> keep abstention, do not relabel components into novelty.

If the new rule simply produces more ideas after every negative, it fails.

## 7. New selector state transition

`Residual -> favorite/clean repair -> prior/probe -> live/die`.

New:
`Residual -> pressure-ranked interface -> mechanism portfolio -> complete-claim screens -> one discriminating family probe -> preregistered handoff -> candidate or bounded abstain`.
